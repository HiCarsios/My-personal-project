# My-personal-project
My Own Pokemon randomizer

The goal of this is to be able to give a random pokemon and give it random traits depending on what you want it to be.

The main thing I wanted was a balanced random stat distributor and balanced typings so that it felt more like a real pokemon rather than a mismatch of stats.

I also hope to include some extra features to hopefully make it so everyone would be happy to use it.

I know it has been done but this was the most middle ground between my Ai agent and a basic text adventure since I do not feel confident in art inputs and such

How to use:
Most instructions are explanitory and simply answer the question, certain sections can take multiple inputs and will take all inputs (1 2 3 and 4)

You can either generate a random Pokemon or set of pokemon or generate a whole list of every pokemon and see some fun new stats for it

When looking up pokemon there can be some confusion on looking up pokemon forms they will be written as "Name, "Form" for example "Terapagos, Stellar Form", "Indeedee, Male", "Urshifu, Single Strike Style". Megas will be "Medicham, Mega Medicham" Regionals will be "Avalugg, Hisuian Avalugg"
When using lookup most of the options from earlier do not matter as they only work with a limited amount of pokemon.
Using the lookup mode you can save the list of Pokemon you generated so your friends can see it if you want everyone on the same list.
